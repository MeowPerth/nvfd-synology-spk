风扇曲线

曲线必须随温度升高不下降。保存后 NVFD 约 5 秒内生效；只有“曲线”模式的 GPU 会使用它。

说明

  • 风扇最低 30%，最高 100%。手动模式会忽略温度，但 NVFD 的 86 °C 失效保护仍会强制全速。
  • 核心/显存偏移通过 NVML VF 接口应用，写入 /etc/nvfd/clocks.json，开机由服务自动恢复。
  • 显存偏移单位是 MT/s（等效频率），实际时钟变化约为一半。例如 -1600 MT/s ≈ -800 MHz。核心和显存输入范围都会实时读取显卡驱动报告的范围。
  • 正偏移属于超频，可能让正在运行的计算任务出错；建议从小数值开始测试。
  • 功耗上限修改后立即生效，但重启后会恢复默认；偏移和风扇模式会保留。
  • 如果某个风扇“目标”大于 0 而“实际”为 0，通常是风扇未接、测速线未接或风扇损坏。
